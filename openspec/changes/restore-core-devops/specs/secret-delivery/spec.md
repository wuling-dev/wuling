# Spec Delta

## Purpose

为可信构建提供必要凭据，同时避免机密出现在普通 API、工作流快照、数据库明文或任务日志中。机密访问以仓库、任务和执行尝试为边界，不因拥有 Runner 身份而获得全局读取能力。

## ADDED Requirements

### Requirement: 加密存储与管理
Secrets MUST 使用外部持久主密钥加密存储，只有仓库维护者可增删改；普通列表只返回名称和元数据，不回显明文，未配置密钥时必须拒绝写入。

#### Scenario: 缺少主密钥
- **WHEN** 未配置持久主密钥而用户尝试保存 Secret
- **THEN** 操作失败且不以临时密钥静默保存

### Requirement: 授权下发与脱敏
机密 SHALL 仅发给获得任务租约的 Runner，不进入工作流快照；不可信 MR 不得获得机密。日志 MUST 在持久化前脱敏包含机密和执行凭据的内容，包括跨块拆分值。

#### Scenario: 分块日志包含机密
- **WHEN** 一个机密值被拆成两个连续日志块上报
- **THEN** 日志存储与用户读取结果均不包含可还原的该明文值

#### Scenario: 不可信 MR
- **WHEN** 未获信任的来源触发 MR 工作流
- **THEN** 系统拒绝注入仓库 Secrets，不允许工作流自行声明为可信以绕过限制
