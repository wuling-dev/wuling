# Spec Delta

## Purpose

将现有 Issue 记录扩展为团队能够分工和持续讨论的任务入口，支持稳定的详情链接、可追溯作者、评论、指派和标签，并使检索与修改始终遵循所属仓库的访问规则。

## ADDED Requirements

### Requirement: 详情与讨论
系统 SHALL 提供 Issue 详情链接、作者与时间、评论、编辑标题正文、关闭和重开；修改他人内容 MUST 要求维护者权限，作者可以修改自己的内容。

#### Scenario: 团队讨论
- **WHEN** 开发者在可访问仓库的 Issue 详情中发表评论
- **THEN** 评论记录作者与时间，刷新及重启后仍存在

#### Scenario: 禁止跨仓库访问
- **WHEN** 用户用可访问仓库的 URL 引用另一私有仓库的 Issue ID
- **THEN** 系统拒绝读取或修改该 Issue

### Requirement: 任务分工和列表
系统 SHALL 支持仓库成员指派、仓库标签、状态与指派人过滤及有界分页；非法指派或标签不能写入。

#### Scenario: 按负责人筛选
- **WHEN** 用户选择负责人和打开状态
- **THEN** 列表仅包含符合两个条件的可访问 Issue，并提供后续分页
