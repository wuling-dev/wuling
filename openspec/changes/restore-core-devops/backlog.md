# 未恢复与延后能力

本文件是范围清单，不是已交付声明。当前主闭环的未完成工作以 tasks.md 为准；
下面项目不属于当前 change 的实现承诺，不能因缺少复选框而视为完成。

| 能力 | 当前差距 / 延后内容 | 重新评估条件 |
| --- | --- | --- |
| GitHub OAuth 与注册审批 | 首批仅本地账号，审批、账号关联和 OAuth 平台均未恢复 | 团队需要外部身份登录 |
| 组织与项目层级 | 首版仓库直属用户，未恢复组织邀请、项目和组织级权限 | 跨仓库组织治理需求 |
| SSH 与 SSH keys | 首版仅 Git HTTPS/PAT | 客户端或运维明确要求 SSH |
| 仓库导入与旧 Go 数据 | 不承诺旧库自动迁移、远程 URL 导入、镜像同步 | 有真实源数据和迁移验收样本 |
| 高级 MR | fork、squash、行内讨论、CODEOWNERS、复杂策略 | 基础版本评审闭环稳定 |
| 实时协作 | 未提交编辑同步、CRDT、多人 checkout 复制、会话回滚 | 有独立同步协议与产品规格 |
| Wiki | 当前仅纯文本记录；安全 Markdown、路径导航和历史版本未恢复 | 主协作闭环完成后安排独立 change |
| Insight | 当前仅数量汇总；提交趋势、构建耗时和历史分析未恢复 | 有真实事件历史可验证 |
| CI 高级语法 | matrix、完整表达式、第三方 Actions、复用工作流 | 最小 gRPC CI 稳定后按兼容测试恢复 |
| CI 制品与缓存 | 上传下载、保留策略、远端缓存与对象存储未恢复 | 有实际交付产物或构建性能需求 |
| 多平台 Runner | Windows/macOS、安装器、工具缓存未恢复 | Linux 执行和协议验收后 |
| 云与 GitOps Runner | AWS/阿里云扩缩容、config 仓库配置与高级隔离池未恢复 | 静态 Runner 容量不足且具备云联测资源 |
| GitHub App | Webhook、同步、PR Checks 回写未恢复 | 明确外部 GitHub CI 场景 |
| 通知与个人设置 | 订阅/通知、头像、第三方授权应用未恢复 | 主协作可用后明确渠道与隐私边界 |
| 项目管理扩展 | Backlog、Sprint、测试计划未恢复 | Issue 最小协作不足以满足团队需求 |
| 扩展平台 | 注册表、CLI、编辑器、移动端、云开发、APM/MCP 等未恢复 | 独立产品提案，不作为“基本能用”前提 |
