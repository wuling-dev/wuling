# 武陵工作台设计约定

产品为小团队自托管仓库协作工具，不做营销数据大屏。
保留 `themes/` 的既有 OKLCH token；下列 hex 仅是默认浅色方向的阅读参考，
CSS 以原 token 为准，不建立第二份颜色来源：

| 角色     | 参考色    |
| -------- | --------- |
| 雾青底   | `#EAF7F8` |
| 内容面   | `#FAFFFF` |
| 正文墨色 | `#142627` |
| 次要文字 | `#526F72` |
| 青色操作 | `#57888C` |
| 紫霄强调 | `#8863DA` |

标题与正文使用系统中文无衬线；IBM Plex Mono（Google Fonts CDN，OFL 1.1）
用于仓库名、分支、路径和代码，不用等宽字装饰普通标签。
字号为 14 / 16 / 20 / 32–40，landing 标题上限 72px；内容左对齐，
正文限制约 72ch，代码块独立横向滚动。

```text
产品标识    工作台 / 系统文档                       外观
                                         当前账号 / 令牌
仓库标题 + 描述                                主要动作
概览 / 代码 / Issue / MR / 流水线 / Wiki / 成员
文件导航                    文本内容
```

曾比较过黑底绿光开发者模板与当前雾青工作台：前者与品牌无关，舍弃。
记忆点留给原有桥柱标识和清晰的仓库路径；不增加统计卡片、编号、渐变或自动入场动效。
表单和阅读面板分组，列表不用一条记录一张卡片。

质量要求：375px 可重排、键盘焦点可见、表单有标签、错误说明下一步，
不以颜色单独表达权限或状态；尊重 reduced motion。原生暗色 token 同时保留。
历史记录必须标明只读，不能将导入的流水线状态表现为真实 CI。
